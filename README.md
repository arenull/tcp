更新地址:https://arenull.github.io/tcp/ 或 https://flq.42web.io 或 https://f27-preview.runhosting.com/raids.eu.org 
1. 支持TCP和UDP协议，支持 TCP Server、TCP Client、UDP单播、UDP组播四种工作模式;
2. 支持ASCII/Hex发送,发送和接收的数据可以在16进制和ASCII码之间任意转换，支持发送和显示汉字;
3. 支持文件发送, 支持接收数据存储文件,dat数据类型与txt文本文件;
4. 支持周期时间发送;
5. 支持快捷与批量发送;
6. 支持远程地址ping功能;
7. 支持自动回传,收到信息自动返回;
8. 支持检查在线更新;
9. 支持发送数据内容区回退、前进快捷键操作;
10. 支持文本转十六进制存储文件功能,发送设置ascii码文件发送,按十六进制数据发送,文本文件以空格区分字节不足字节前0填充,接收端接收设置hex十六进制文件存储;
11. 支持单次最大发送数据N字节设置,非周期默认一次发送全部数据,周期发送按设置字节数发送;
11. 支持发送数据区~分割周期发送,通过勾选周期时间循环发送，如11~22~AABBCCDD;
